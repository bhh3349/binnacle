## 三、修复明细（提交 5e280d2）

| # | 问题 | 严重度 | 根因 | 修法 |
|---|---|---|---|---|
| 1 | PDF 预览空白 | **高** | 后端 `Content-Disposition: attachment` | 新增 `?inline=1`，预览用 `inlineUrl` |
| 2 | 复制路径静默失效 | **高** | HTTP 非 secure context 无 `navigator.clipboard` | clipboard → execCommand → prompt 三级降级 |
| 3 | 时间排序无效 | **高** | `fsList` 把 mtime 排除在 order 逻辑外 | mtime 单独处理 asc/desc |
| 4 | 在终端打开不 cd | **高** | 只复制命令到剪贴板 | `binnacle:term-run` 事件 → PTY 写入 |
| 5 | 文件名截断 | 中 | 左栏窄 + 三列固定宽 | 窄栏隐藏权限列、收紧列宽、紧凑时间 + title |
| 6 | 解压双嵌套 | 中 | 目标目录与 zip 顶层目录同名 | `archiveHasTopDir` 检测后解到父目录 |
| 7 | 上传静默覆盖 | 中 | 无存在性检查 | 上传前 stat + confirm |
| 8 | 终端误关 | 中 | 关闭无确认 | 有输出时 confirm |
